Paw & Pour

Security training demo

A pet café's staff console, on purpose broken and then fixed.

Two versions of the same small staff-management app for a fictional pet café: one has five common web vulnerabilities left in, the other has each one patched. Everything runs client-side against mock data — safe to click through together as a team.

→

Vulnerable console

SQL Injection login bypass, unescaped XSS in search, CSRF on account settings, a readable session cookie, and no frame protection.

 →

Patched console

Same UI and data, with safe lookups, escaped output, a CSRF token, a protected cookie, and a framing check.

 →

Clickjacking test

Both consoles loaded in an iframe side by side, to see the difference directly.
See ATTACK_DEMO_GUIDE.md for a presenter script, and SECURITY_REPORT.md for the full written report.
